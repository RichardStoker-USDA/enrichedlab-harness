# Run versions

Extend the notebook ledger in the web workbench. The proof object is one delivered version with an immutable receipt. The scientist arrives to open the newest result, see what is still being checked and leave direction for the next version.

The objective heads a single reading column. A dated rule joins the delivered versions, newest first. Expanding a version opens its original artifact and verification details directly below its title. An open step and steering controls sit above the deliveries. Feedback joins the run's event history. A keyboard user can move through the same controls in document order.

Use the harness's UC Davis semantic colors, system typography and tabular time. The narrow layout moves metadata below its title and keeps controls at least 44 px tall. Reuse the persisted theme. A failed artifact check leaves a readable error in its place. Reduced motion preserves the position of the opened version.
